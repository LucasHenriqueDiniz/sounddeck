Como instalar

  1. Baixe e abra o instalador. Não é preciso ser administrador.
  2. Escolha um pack na biblioteca e ouça a prévia.
  3. Clique em aplicar. O esquema anterior é salvo automaticamente.

Requisitos

  • Windows 10 versão 1809 ou mais recente, ou Windows 11.
  • Cerca de 30 MB de espaço em disco.
  • Nenhum runtime extra: o app usa o WebView2 já presente no sistema.

De onde vêm os binários

Cada versão é compilada automaticamente pelo GitHub Actions a partir do código-fonte nesta tag, sem passar por uma máquina pessoal. O link acima leva direto para a página da release no GitHub.
